# Roadmap

Grind keeps a deliberately small core. Potential work should start with an
issue and preserve the offline, account-free default.

## Near term

- Add a kilogram/pound display preference without rewriting stored values
- Add Firefox to the automated browser matrix
- Add optional CSV export alongside the complete JSON backup
- Improve screen-reader announcements for rest completion

## Later

- User-defined workout templates through an in-app editor
- Explicit equipment profiles for home, hotel, cable, and barbell setups
- Optional encrypted multi-device sync through a separately deployed backend

## Not planned

- First-party accounts or hosted workout data
- Advertising or behavioral analytics
- Medical, rehabilitation, or individualized coaching claims
